## 简介
在目录内/收藏页面右下角"用户名"左边添加“批量操作”按钮

可将页面内条目的收藏状态改变（wish / collect / do / on_hold / dropped 以及从收藏中删除）
在自己的目录中，还可以选择从目录中删除。在其他人的目录，可以选择从条目添加到自己的目录（输入目录id / 选择建立目录）
